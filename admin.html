🍽️ Panel Guru

Panel guru: kelola murid, soal, token akses, dan nilai. Semua langkah dijelaskan di bawah.

🏠 Menu Utama

Belum punya akun? Klik tab Daftar Baru di atas.

Cara mulai:
1. Isi nama dan PIN, lalu klik Buat Akun Guru.
2. Setelah masuk dashboard, pilih paket pembayaran (Rp 10.000 / 3 hari).
3. Bayar lewat QRIS/GoPay/DANA/ShopeePay/Virtual Account.
4. Akun otomatis aktif, lalu buat token untuk siswa.

Guru

📋 Panduan Langkah demi Langkah

  1. Aktifkan kelas: Pilih paket pembayaran di kartu Langganan (mulai Rp 10.000 / 3 hari) atau masukkan kode aktivasi.
  2. Data murid: Tambahkan satu-satu, tempel banyak sekaligus, atau biarkan siswa mengisi namanya sendiri di game.
  3. Buat token: Klik "Buat token hari ini" di kartu Token Akses Siswa.
  4. Bagikan token: Tulis kode token 6 karakter di papan tulis, siswa masukkan di game.
  5. Lihat nilai: Klik "Muat rekap" di kartu Rekap Nilai untuk melihat hasil siswa.

🎟️ Token Akses Siswa (Bagikan ke Murid)

Token ini dipakai siswa untuk masuk ke game. Satu token berlaku untuk semua murid, sampai besok.

⭐ Langganan (Aktifkan Kelas)

Pilih paket pembayaran otomatis (Midtrans) atau masukkan kode aktivasi.

Cara mengaktifkan:
1. Pilih salah satu paket di bawah (mulai Rp 10.000 / 3 hari).
2. Klik tombol paket, lalu bayar lewat QRIS/GoPay/DANA/ShopeePay/Virtual Account.
3. Setelah bayar, akun otomatis aktif dan Anda bisa membuat token untuk siswa.

Pembayaran paket di atas diproses otomatis lewat Midtrans (QRIS, GoPay, DANA, ShopeePay, Virtual Account). Jika punya kode aktivasi dari pemilik, masukkan di atas.

🧒 Murid

Bisa ditambah satu per satu, ditempel banyak sekaligus, atau diisi langsung oleh siswa saat masuk game (maksimal 50 murid).

+ Tambah Banyak Murid Sekaligus (Copy-Paste Daftar Absen)

Format per baris: Nama atau Nama, Kelas atau Nama, Kelas, PIN.

📝 Soal tambahan

Soal ini otomatis masuk ke game sesuai organ dan level. Soal bawaan game tetap ada, jadi tidak wajib diisi.

📊 Rekap nilai

Nilai semua murid, per kelas, dan per materi. Klik Muat rekap untuk melihat.
